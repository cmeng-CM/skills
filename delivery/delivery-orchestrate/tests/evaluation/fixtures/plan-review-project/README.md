# Ledger report fixture

这是一个无第三方依赖的 Python 项目。`app.py` 是当前用户实际运行入口，输入样本为 `transactions.json`；现阶段还没有业务聚合模块，实现安排见 `plan.md`。

公开交付要求：新增账本汇总命令，读取 JSON 交易列表，输出按币种分别汇总的收入、支出和净额。共享交易契约供收入与支出两个功能使用；实际命令入口必须接入两个分支。金额用十进制精确到分；收入和支出的原始 amount 均为正数，由 kind 决定方向。未知币种允许独立汇总；空列表输出空对象；无效金额、kind 缺失或未知、非列表输入均返回非零且不输出部分结果。输出以币种键排序，金额是两位小数字符串。不要增加网络或数据库依赖。

运行：`python3 app.py transactions.json`。示例中 CNY 收入 10.10、支出 2.05，结果 CNY 的 income=10.10、expense=2.05、net=8.05。USD 不与 CNY 混合。

验收包含共享契约、两个业务分支、真实入口和联合测试；修改后保存可读说明。单项调用按其专业边界处理，完整流程才组织全部阶段。此目录没有 Git，也没有 `.workflow`。
