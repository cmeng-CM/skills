# Qwen-Image 文生图

DashScope 原生接口（非 OpenAI 兼容协议），同步返回图片临时 URL，脚本自动下载落盘。不能作为任何客户端的主模型——只作为工具被主模型调用。

## Working Protocol

### 1. 路由判断（先于执行）

| 输入与诉求 | 走向 |
|---|---|
| 从文字生成新图（插画、海报、配图、示意图） | 本 skill |
| 看图、读图、图片问答 | 视觉模型直读，不启动本 skill |
| 修改已有图片（局部重绘、去字、换背景） | 本 skill 不支持，如实告知 |
| 批量配图（文档多图、分镜） | 本 skill 逐张调用，文件名前缀区分 |

### 2. 执行生成

```bash
python3 scripts/qwen_image.py "提示词" [--size 宽*高] [-n 张数] [--negative 反向提示词] [--no-extend] [--out 目录] [--name 前缀]
```

- 模型默认 `qwen-image-3.0-pro`；若报模型不存在（新模型未全量时），改 `--model qwen-image-2.0-pro`
- `--size` 默认 `2048*2048`；推荐 `2688*1536`（16:9）、`1536*2688`（9:16）、`2368*1728`（4:3）、`1728*2368`（3:4），总像素限 512*512 至 2048*2048 之外上限按 2.0 系列文档，报错就换推荐值
- `--no-extend` 关闭提示词智能改写：用户强调细节、构图、文字内容时加
- 输出目录默认 `~/workspace/temp/yyyyMMdd`（当天日期），用户另有指定时从其指定
- 提示词支持中文，上限约 800 Token（2.0 系列约 1300），超长自动截断；报版面/试卷/报纸类复杂文字图时提示词里显式写清文字内容

### 3. 前置条件与失败处理

- 依赖 `DASHSCOPE_API_KEY`（百炼 API Key）：未设置时脚本退出码 2 并给指引，不要重试
  - 设置方式：`echo 'export DASHSCOPE_API_KEY=sk-xxx' >> ~/.zshrc && source ~/.zshrc`
- 计费约 0.18 元/张起：单次生成默认 1 张，用户没要求不要批量多张试错
- API 返回的 URL 24 小时失效——脚本已当场下载，不要只把 URL 给用户
- 失败只报告报错原文与已排除原因，不静默改提示词重试超过一次

## Exit Criteria

- [ ] PNG 已落盘并告知用户完整路径
- [ ] 生成张数、尺寸与用户要求一致
- [ ] 编辑已有图片类请求已说明不支持

## Exit Protocol

交付时报告：图片路径、尺寸、张数。用户要改图时说明本 skill 仅文生图，改图需求如实告知无法完成。
