没有未处理的阻断发现。以下是需保留的真实边界，不是隐藏的通过豁免：

1. 已有问题历史的 owner 与关联任务 ID 暂不能迁移或移除。允许保留原组用于复审并增设新组，真正新目标另建关联目录。它会增加复杂重组成本，已记 decisions.md。
2. 独立命令证据不能导入为引擎 command 的历史 run。组合时需安全取得新真实回执；不可安全重跑就待验，不能改成 inspection 绕过。现有独立报告和事实仍保留。后增契约段未改变之前独立验证的工作内容，无需伪改历史快照。
3. 语义映射、真实授权与实际独立性仍依赖专业判断和可信记录；脚本只是检查可确定的条件。首版 POSIX 本机运行、不支持分布式写入或符号链接产品范围。
4. 本次有限演练与回归支持首版交付判断，不能证明所有任务、模型和后续 skill 更新均不会退化。后续更新须继续执行契约影响检查与代表性行为回归。
