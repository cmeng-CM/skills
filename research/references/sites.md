按资源类型查本表，只读取相关条目。本表承接旧路由包的历史记录；**历史实测是当时、该环境、该次请求的观察，不是本次验证或当前可用性保证**。首次依赖某路线时，按当前工具能力检查实际返回；不要照搬旧凭证、登录态或永久不可用结论。

## 已有线索

### skills.sh：Agent Skills 目录

- **状态**：历史实测，2026-09-27；本轮未重验。
- **覆盖**：已收录的 agent skill，可与源仓库搜索互补。
- **检索**：历史上使用网页搜索限定 `skills.sh`，查询功能词；返回过 skill 摘要和 SKILL.md 片段。片段仅作候选，需进入原始文件核对。
- **穷举**：历史上首页排行榜、分类页与 `https://www.skills.sh/<owner>/<repo>` 可读取。排行榜不代表全站；要列全指定范围须核对当前目录、分页与结束条件。
- **保底**：平台代码搜索或 `gh search code --filename SKILL.md "<关键词>"`；两者收录不同，任一路线无结果不代表不存在。
- **注意**：页面结构与搜索框实现可能变化。安装量与审计字段可提供线索，不自动证明质量或安全性。

### GitHub：代码、仓库与原始文件

- **状态**：历史实测，2026-09-27；本轮未重验接口或本机凭证。
- **覆盖**：仓库、源码、issue 及原始文件；不同搜索入口有各自索引和权限边界。
- **检索**：有可用 CLI 时可用 `gh search code --filename <文件名> "<关键词>"`；找仓库可用 `gh search repos "<词>"`。连接器或平台原生搜索也可承担同一动作。
- **穷举**：确认分支／版本后读取 `gh api "repos/<owner>/<repo>/git/trees/<ref>?recursive=1"`，检查 `truncated`；需要时分层列树。搜索命中数不能替代仓库文件遍历。
- **取原文**：可用 contents API 或 `https://raw.githubusercontent.com/<owner>/<repo>/<ref>/<path>`；检查编码、内容类型与实际返回，记录所用版本。
- **保底**：平台网页、可访问的源文件或文档；通用检索可发现入口，但不能据此声称代码覆盖完整。
- **注意**：先列树定位真实路径；默认分支和搜索限制可能变化。近期讨论工具只适合补充讨论证据，不能代替源码检索。

### designdocs.dev：公开设计文档目录

- **状态**：历史实测，2026-09-27；本轮未重验。
- **覆盖**：公开设计文档、RFC、KEP 等资料入口。
- **检索**：历史入口为 `https://www.designdocs.dev/library`，也可通过站内限定检索发现条目。
- **穷举**：旧记录以 `tavily_map` 的 `max_depth: 1`、`max_breadth: 30`、`limit: 40` 返回过 30 条链接。**这只是一次限量结果，不能证明目录列全**；当前全量请求须重新检查导航、分页、限制与结束条件。
- **保底**：相关项目的官方 RFC／设计文档仓库与相应主题的公开清单；仍应回到原始文档。
- **注意**：用户要全目录才做有界穷举；找某主题资料时选择相关条目即可。目录链接不等于已读各文档。

### X / Twitter：帖子与讨论

- **状态**：历史实测，2026-10-12；本轮未重验登录或后端。
- **覆盖**：帖子、当事人发言与讨论线索，不代表全部用户观点或完整历史。
- **检索**：旧环境使用 `opencli twitter search "<query>" --limit 20 -f json`；时间筛选曾使用 `since:`，近期排序曾使用 `--product live`。当前命令与操作符按已安装工具说明核对。
- **穷举**：无本表已验证的全量路线；提高 limit 或自动翻页不能证明平台全量。
- **保底**：当前可用的其他 X 后端、网页索引；时间窗讨论可用已安装且对应渠道可用的 last30days。其他平台只作不同来源，不能冒充 X 数据。
- **注意**：旧记录中的 Chrome 桥接、CLI 端点失败、备用实例与 cookie 状态均是当时观察。不要自行登录、提取或刷新凭据；在现有授权与工具能力内读取，失败时报告实际原因。Top 排序可能混入旧内容，应检查帖子日期而非只看检索时间。

## 维护边界

研究时只把本次可用性、失败和覆盖写入研究结果，不自动维护本表。发现长期有价值的新站或旧路线失效时，可提出具体更新内容及证据；只有明确要求维护后才写入。

获准更新时，保留覆盖、检索、穷举、保底与注意事项，状态注明日期、实际动作及成功或失败范围；未跑过的路线标未实测。优先收录有持续用途、能补充现有发现范围的入口，不把一次性页面或猜测的命令写成已验证路线。
